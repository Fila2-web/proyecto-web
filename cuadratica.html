¿Qué es una ecuación cuadrática?

Es una ecuación de segundo grado cuya forma general es ax² + bx + c = 0, donde a debe ser diferente de cero.

Fórmula general:

x = (-b ± √(b² - 4ac)) / 2a

El discriminante es D = b² - 4ac. Si es positivo, hay dos raíces reales distintas; si es cero, hay una raíz real doble; y si es negativo, no hay raíces reales.

Ejemplo resuelto

Resolver: x² - 4x + 3 = 0.

1. Identificamos: a = 1, b = -4, c = 3.

2. Calculamos el discriminante:
D = (-4)² - 4(1)(3) = 16 - 12 = 4.

3. Sustituimos en la fórmula:
x = (4 ± √4) / 2.

4. Calculamos las dos raíces:
x₁ = (4 + 2) / 2 = 3.
x₂ = (4 - 2) / 2 = 1.

Soluciones: x = 3 y x = 1.
